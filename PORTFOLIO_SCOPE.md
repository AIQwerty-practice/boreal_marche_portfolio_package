# Portfolio package scope

This repository is designed for public technical review, deliverable submission, and teammate replication.

- It contains source, tests, safe example configuration, documentation, and one generated architecture diagram required by the application.
- It documents the commands and example environment variables a classmate needs to reproduce the system from a clean clone; secrets are never committed.
- It does not contain reports/PDFs, screenshots, presentation/video links, a deployable copy of the original AWS account configuration, credentials, raw data, customer-level outputs, internal notes, or evidence requiring restricted access.
- D1–D7 are complete for the project. This portfolio package remains deliberately narrower than the private project workspace and release record.
- The private AWS deployment workflow is intentionally excluded. Its absence is a package boundary, not a failed local-app capability: a classmate can reproduce the app locally without an AWS account.

Any downstream deployment must use a new environment, new credentials, and a separate security/privacy review.
