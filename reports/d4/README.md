# D4 evidence boundary

The public portfolio package contains the D4-capable application, tests, safe deployment templates, and the manual OIDC workflow. It deliberately excludes operational screenshots, account-specific deployment evidence, and the full assessment reports.

For the final submitted evidence set, consult the separate [Boreal Marche release package](https://github.com/AIQwerty-practice/boreal_marche_release_package). Any deployment from this public package must use a separate AWS account, repository variables, and OIDC role; no account identifiers or credentials are stored here.
