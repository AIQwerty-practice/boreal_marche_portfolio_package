# Reproducibility record

## Standard

The Capstone Project requires an independent classmate to clone this repository on a clean machine and bring the system up with the documented commands. Required environment-variable names are provided in `.env.example` and `deploy/aws/.env.example`; secret values must never be committed.

## Current package

This public D1–D7 portfolio package supplies the source, tests, safe configuration examples, source-data ingestion command, and local-start documentation needed for a clean-clone exercise. It intentionally does not distribute raw or generated customer-level data, cloud credentials, or original cloud-account configuration.

## Clean-clone verification handoff

The instructor coordinates the independent clean-clone check with students using this public repository. That grading activity does not require a new private project record. A reviewer should capture locally:

1. Operating system and Python version on the clean machine.
2. Exact clone, install, ingestion, test, and local-start commands run.
3. Test result, API readiness result, and any reproducibility issue/correction.
4. The exact release commit SHA and final artifact checksums.

The project’s final release and defence materials are complete. The instructor-led clean-clone exercise remains a grading activity rather than a new project implementation task.
