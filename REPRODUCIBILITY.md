# Reproducibility record

## Standard

Week 11 requires an independent classmate to clone this repository on a clean machine and bring the system up with the documented commands. Required environment-variable names are provided in `.env.example` and `deploy/aws/.env.example`; secret values must never be committed.

## Current baseline

This D4 baseline supplies the source, tests, safe configuration examples, source-data ingestion command, and deployment documentation needed for the exercise. It intentionally does not distribute raw or generated customer-level data, cloud credentials, or original cloud-account configuration.

## Planned final verification record

Before D7 closure, the project will record:

1. Operating system and Python version on the clean machine.
2. Exact clone, install, ingestion, test, and local-start commands run.
3. Test result, API readiness result, and any reproducibility issue/correction.
4. The exact release commit SHA and final artifact checksums.

Until that independent run is recorded, this repository must not claim a completed clean-machine verification.
